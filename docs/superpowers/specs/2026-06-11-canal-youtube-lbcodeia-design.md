# Canal YouTube LBCode.IA — Design Spec

**Data:** 2026-06-11  
**Status:** Aprovado

---

## Conceito

Canal YouTube da LBCode.IA mostrando como o projeto foi construído do zero com IA. Screencast + narração, sem aparecer na câmera.

**Posicionamento:** "aprendi fazendo, te mostro como" — honesto, erros aparecem, decisões explicadas em voz alta.

**Público:** Iniciantes curiosos sobre Claude Code, automação e dev com IA. Não precisam saber programar.

**Objetivo primário:** Ensinar o que está sendo aprendido. Efeito secundário: brand awareness e geração de leads para LBCode.IA.

---

## Estrutura de Conteúdo

### Série Principal — "Como construí o LBCode.IA"

Playlist cronológica contando a história real do projeto. ~8-12 episódios.

| Ep | Tema |
|----|------|
| 1 | Conceito: por que NotebookLM pra organizar projeto de IA |
| 2 | Primeira skill: entrevista inicial que aprende sobre o negócio |
| 3 | Carrossel automático: design salvo + geração de imagem |
| 4 | Skills de tráfego: Meta Ads + Google Ads com IA |
| 5 | Integração live: puxando dados reais de APIs |
| 6 | Sites gerados por IA com design system |
| 7+ | Skills avançadas que surgiram no caminho |

### Laboratório — vídeos avulsos

Tópicos independentes sem precisar ver a série. Exemplos:
- "Como usar Claude Code do zero"
- "NotebookLM pra iniciantes"
- "O que é uma skill de IA"

Cada vídeo de laboratório tem SEO próprio e pode servir como porta de entrada pro canal.

---

## Formato de Cada Vídeo

Duração: ~10-20 min. Estrutura padrão:

1. **Hook (0-30s)** — mostrar resultado final primeiro
2. **Contexto (1-2 min)** — o problema que motivou, explicado pra iniciante
3. **Mão na massa** — screencast do Claude Code em ação, narração de decisões, erros incluídos
4. **Resultado (1-2 min)** — mostrar funcionando, o que foi aprendido
5. **CTA simples** — próximo episódio ou link WhatsApp LBCode.IA

---

## Stack Mínima

- **Gravação:** OBS Studio (gratuito)
- **Edição:** DaVinci Resolve gratuito
- **Microfone:** razoável (não precisa ser top)
