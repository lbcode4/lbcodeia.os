## 🎬 Padrão de gravação (vale pra todos)

1. **Gancho (0–15s):** mostra o problema real antes de qualquer explicação.
2. **Contexto (15–45s):** "Hoje vou criar a skill X que faz Y."
3. **Criação (núcleo do vídeo):** cola o prompt no Claude Code, mostra o `SKILL.md` nascendo.
4. **Demo:** roda `/skill` no VSCode e mostra o resultado real.
5. **Fechamento:** o que vem no próximo vídeo + CTA.

### Regras de tela
- Fonte do terminal/editor grande (legível no celular).
- Esconder tokens/credenciais reais (usar `.env.example`).
- Mostrar o arquivo gerado em `saidas/` quando houver output.
- Cortar esperas longas (render Playwright, chamadas de API) com jump-cut.

### Framework é o diferencial — repetir em todo vídeo
Toda skill de marketing usa ≥1 pilar: **RETINA** (posicionamento), **GCC** (gatilho/copy/conversão), **OPA** (oferta), **Bolo de Cenoura** (nutrição), **4 Campanhas de Ouro** (mix de tráfego). É isso que separa o LBCode.IA de "pedir pro ChatGPT".
