# scripts/prompts — Biblioteca de prompts equivalentes aos agentes do curso

8 templates prontos pra rodar via Claude (não dependem de GPT externo).

Cada `.md` contém:
1. **Quando usar** — qual skill chama o prompt
2. **Inputs necessários** — o que pedir ao usuário antes de rodar
3. **Prompt completo** — copiar-colar pro Claude ou usar como base de geração
4. **Output esperado** — formato do que deve voltar

## Princípio

**Primeiro cérebro + segundo cérebro:** sempre alimentar com material validado (anúncio campeão, post que funcionou, persona detalhada). Pedido genérico → resposta genérica.
